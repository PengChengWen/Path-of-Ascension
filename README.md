# 问道余烬

一个以挂机修炼为主的单机修仙 RPG 原型。当前版本为 **青岚初境 v0.1**，从炼气六层开始，便于先体验界面和成长循环。

## 本地运行

需要 Node.js 24 和 npm。`.nvmrc` 已声明开发版本，不需要 PHP 或数据库服务。

```bash
npm ci
npm run dev
```

打开开发服务器给出的地址，默认是 `http://127.0.0.1:5173/`。端口固定，避免在切换端口后找不到原有浏览器存档。

## 先这样试玩

1. 点击首页的“炉中残念”，参悟传承后完成第一次突破。
2. 在“山海历练”安排采集，或继续在洞府闭关；“参悟古卷”消耗悟性，可加快体验修为成长。
3. 在“功法典籍”切换剑修、毒火、水土三种预设，并消耗灵石精研功法。
4. 结识沈青禾，完成药庐委托后邀请她同行。
5. 挑战黑旗妖虎，观看自动战斗；可选择一、二、四倍速或跳过演出。战利品只发放一次。
6. 开炉炼制聚灵丹与筑基丹，收集地脉印，为首次筑基做准备。

“通天塔”目前提供界面预览，实际爬塔、后续区域与完整人物故事尚未开放。当前历练是按队列结算材料收益；自动刷怪与装备掉落还未接入。

## 保存与离线

- 进度保存在当前浏览器、当前网址的 IndexedDB 中，通常每十秒保存，关键操作即时保存。
- 离线最多结算十二小时，修炼、已安排的历练与炼丹继续；剧情和突破等待主动选择。
- 同一存档只允许一个页面写入，其他标签页只读。关闭写入页后，刷新其他页面即可接续。
- 在“修行设置”导出或导入 JSON 存档。更换浏览器、网址或清理站点数据之前应导出备份。
- 网页离线收益通过再次打开后补算，不保证断网时能够重新加载页面。当前没有账号与云存档。

## 验证命令

```bash
npm run typecheck
npm run validate:content
npm test
npm run test:e2e
npm run build
npm run format
```

规则测试由 Vitest 执行，浏览器测试由 Playwright 执行。Windows 若安装了标准位置的 Edge，浏览器测试会直接使用它；其他环境可先执行 `npx playwright install chromium`。

`npm run simulate:combat` 为开发用的预设战斗批量模拟工具，不代表全部后续战斗系统已经实现。

## 项目结构

- `src/core`：修炼、时间推进、操作校验与战斗模拟。
- `src/content`：地点、丹方、物品、功法与战斗预设。
- `src/platform`：IndexedDB 存档仓库和文件导出。
- `src/store`：串行操作、存档提交与界面状态订阅。
- `src/ui`：真实可交互页面和 CSS Modules。
- `src/assets`：独立场景美术；界面文字、按钮、血条和进度由组件绘制。
- `tests`：浏览器关键流程测试。

后续对话先读取根目录 `AGENTS.md`。整体策划和视觉参考位于 `docs`，其中未实现的内容仍是规划，不是当前功能清单。

最新的[境界数值与功法成长设计](docs/问道余烬_境界数值与功法成长设计.md)明确了参考《鬼谷八荒》的三阶段境界、功法养成、玩家引导与旧档迁移方案；目前为待实现设计，未替换现有游戏规则。
